Elastic Path · 2024 · UX Designer

Finding a category in a catalog of 10,000+

I designed Elastic Path’s first category search so merchandisers could find a category by name, even when they didn’t know where it lived in the catalog.

The problem

A category name answers one question. A category tree asks another. A merchandiser might know exactly which category they need, yet still have to work out which parent to open and which branch to follow. In a hierarchy with more than 10,000 nodes, each wrong turn adds another round of browsing.

Designing for a known category

I focused on the moment a merchandiser already had a destination in mind. Their starting point was the name they knew. Search gave them a way to use that knowledge directly, without first reconstructing the catalog hierarchy.

What changed

Category lookup became a search-driven workflow. Knowing a category’s name was enough to start looking for it, even in a catalog someone else had organized.
